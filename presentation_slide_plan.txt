SLIDE 3 - The one idea behind every method (theory foundation)
---------------------------------------------------------------------
ON THE SLIDE
  Price = discounted risk-neutral expectation = solution of the BS PDE
     C = e^{-rT} E^Q[ max(S_T - K, 0) ]
     S_T = S0 exp( (r - sigma^2/2) T + sigma sqrt(T) Z ),  Z ~ N(0,1)
     dC/dt + r S dC/dS + 1/2 sigma^2 S^2 d2C/dS2 - r C = 0,  C(S,T) = (S-K)^+
  Map: MC = samples the expectation, tree = enumerates it on a lattice,
       FD grid = solves the PDE, BS = solves it in closed form.
VISUAL   diagram: "Expectation (MC, Tree)" <-- Feynman-Kac --> "PDE (FD, BS)"
PROOF TO SHOW (short derivation of the PDE, as in Continuous.pdf):
  1. Ito on C(S,t):
     dC = (C_t + mu S C_S + 1/2 sigma^2 S^2 C_SS) dt + sigma S C_S dz
  2. Portfolio Pi = C - Delta S. Choose Delta = C_S so the dz term drops out.
  3. Riskless => dPi = r Pi dt (no arbitrage)
     => C_t + r S C_S + 1/2 sigma^2 S^2 C_SS - r C = 0
  4. mu has disappeared, so we can price as if mu = r (risk-neutral pricing).
UNDERLYING
  - Feynman-Kac: the solution of this parabolic PDE equals the conditional
    expectation of the discounted payoff under the measure where S drifts at r.
  - Ito's lemma for ln S: d ln S = (mu - sigma^2/2) dt + sigma dz, so S_T is
    lognormal. This gives the exact simulation formula used in MC (no time
    discretisation error).
SAY      "All four methods compute the same number in different ways, so they
          have to agree. The question is how fast and how precisely."

SLIDE 6 - Monte Carlo: method and convergence
---------------------------------------------------------------------
ON THE SLIDE
  Algorithm: draw Z_i, compute S_T^i, average the discounted payoffs.
  C_hat = e^{-rT} (1/M) sum_i (S_T^i - K)^+
  SE = std(X)/sqrt(M):  M = 100 -> 1.0;  M = 10^6 -> 0.014;  M = 10^8 -> 0.0014
  "4x more paths = 2x smaller error"
VISUAL   notebook: "Simulated GBM paths" + "Distribution of S_T (lognormal)"
         and "Standard error (log-log)" with slope -1/2
PROOF TO SHOW (1/sqrt(M) rate)
  X_i i.i.d., E[X] = C, Var(X) = s^2
  Var(C_hat) = Var( (1/M) sum X_i ) = (1/M^2) * M * s^2 = s^2/M
  => SE = s/sqrt(M)
  CLT: C_hat ~ N(C, s^2/M) approx. => 95% CI = C_hat +/- 1.96 SE
UNDERLYING
  - Strong law of large numbers: C_hat -> C almost surely (consistency).
  - Unbiasedness: E[C_hat] = C exactly, because S_T is sampled from its exact
    distribution (no Euler discretisation).
  - Our s is about 14 (from SE = 0.014 at M = 10^6).
  - The rate does not depend on the dimension of the problem. That is why MC
    wins for multi-asset and path-dependent options.
SAY      "MC is unbiased but noisy, and the noise only falls with the square
          root of the effort."

---------------------------------------------------------------------
SLIDE 7 - Binomial tree (CRR): method and convergence
---------------------------------------------------------------------
ON THE SLIDE
  dt = T/N,  u = e^{sigma sqrt(dt)},  d = 1/u,  p = (e^{r dt} - d)/(u - d)
  Backward induction: C(i,j) = e^{-r dt} [ p C(i+1,j+1) + (1-p) C(i+1,j) ]
  Error: N = 1 -> 1.8;  100 -> 0.02;  1,000 -> 0.002;  10,000 -> 0.0002
  Error ~ 1/N, oscillating (odd/even N)
VISUAL   notebook: small CRR tree picture + "Convergence of the tree price"
         (zig-zag) + "Error (log-log)" with slope -1
PROOF TO SHOW
  (a) One-period replication (Replication_One_Period lecture):
      hold Delta = (C_u - C_d)/(S u - S d) shares + bond, so the portfolio
      matches the option in both states
      => C = e^{-r dt}[p C_u + (1-p) C_d] with p as above. p is a
      risk-neutral probability; it does not depend on mu.
  (b) Moment matching: E[S_{t+dt}] = S_t e^{r dt} (exact by choice of p),
      Var[ln S_{t+dt}/S_t] = sigma^2 dt + O(dt^2) (from u = e^{sigma sqrt dt}).
UNDERLYING
  - ln S_T is a sum of N i.i.d. +/- sigma sqrt(dt) steps. By the CLT
    (de Moivre-Laplace) it converges to the normal distribution, so the tree
    converges to BS.
  - Error O(1/N). The oscillation comes from the kink of the payoff at K:
    K = 100 = S0 falls exactly on a node for even N and between two nodes for
    odd N.
  - Fixes if asked: average of N and N+1, or Leisen-Reimer tree.
SAY      "The tree enumerates the risk-neutral expectation. Error falls like
          1/N but zig-zags because of the payoff kink."

SLIDE 8 - Finite differences (Crank-Nicolson): method and convergence
---------------------------------------------------------------------
ON THE SLIDE
  Grid in (S, t), S in [0, Smax = 4K]. Start from the payoff at T and step
  backwards.
  Boundaries: V(0,t) = 0,  V(Smax,t) = Smax - K e^{-r(T-t)}
  Derivatives replaced by central differences, CN = average of explicit and
  implicit schemes.
  Doubling the grid divides the error by 4:
  1.22 -> 0.26 -> 0.062 -> 0.015 -> 0.0038 -> 0.00096 -> 0.00024
VISUAL   notebook: 3D "Call value on the grid V(S,t)" + "Error (log-log)"
         with slope -2
PROOF TO SHOW (truncation error by Taylor expansion)
  V(S+h) = V + h V' + h^2/2 V'' + h^3/6 V''' + h^4/24 V'''' + ...
  V(S-h) = V - h V' + h^2/2 V'' - h^3/6 V''' + h^4/24 V'''' - ...
  Subtract: [V(S+h) - V(S-h)]/(2h) = V' + O(h^2)   (even terms cancel)
  Add:      [V(S+h) - 2V + V(S-h)]/h^2 = V'' + O(h^2)  (odd terms cancel)
  Crank-Nicolson is centred at t + dt/2, so the time error is O(dt^2).
  => total error O(dS^2 + dt^2) ~ 1/N^2 when N_S = N_t = N.
UNDERLYING
  - CN is unconditionally stable (von Neumann analysis). The explicit scheme
    from the lecture is only stable if dt <= dS^2/(sigma^2 S_max^2), see
    Numerical.pdf: "can be unstable".
  - Lax equivalence theorem: consistent + stable => convergent.
  - The payoff kink at K can create small oscillations with CN (fix: a few
    implicit "Rannacher" steps at the start). Mention only if asked.
  - Truncating at Smax = 4K: the probability that S_T > 400 is negligible.
SAY      "The grid solves the PDE directly. Thanks to central differences in
          both S and t it is the fastest of our three numerical methods."

SLIDE 10 - Uncertainty in the numerical results
---------------------------------------------------------------------
ON THE SLIDE
  1. MC: statistical error. Random, unbiased, quantified by a CI.
     A different seed gives a different price.
  2. Tree / FD: discretisation error. Deterministic bias, no CI. Size known
     from the convergence order. FD also has boundary/truncation error (Smax).
  3. Model uncertainty dominates: vega = 38.2, so a 1 vol point error in sigma
     moves the price by 0.38, about 200x our MC standard error.
     The model assumes constant sigma, constant r, no jumps.
  Which method is best here? BS (exact). Then CN > tree > MC in speed.
  MC wins for path-dependent and multi-asset options (curse of dimensionality),
  PDE/tree wins for early exercise (American) - Numerical.pdf.
VISUAL   a "variance vs. bias" 2x2 picture, or a bar chart comparing the
         numerical errors (~0.002) with the vega impact of +1 vol pt (0.38)
PROOF TO SHOW
  Error decomposition: price_hat - true = (bias) + (noise)
     MC:      bias = 0,           noise ~ N(0, s^2/M)
     Tree/FD: bias = c N^{-k},    noise = 0
  Model error ~ Vega * (sigma_true - sigma_used) (first-order Taylor in sigma)
SAY      "Our numerical errors are tiny. The real uncertainty is the
          volatility input."

SLIDE 13 - WHY: the gamma-theta P&L of a delta hedge (core proof of Part 2)
---------------------------------------------------------------------
ON THE SLIDE
  P&L of the hedged position over one step dt (long Delta shares + cash,
  short the call):
     d eps = 1/2 Gamma S^2 [ sigma^2 dt - (dS/S)^2 ]
           = 1/2 Gamma S^2 sigma^2 dt (1 - Z^2)   with dS/S ~ sigma sqrt(dt) Z
  "variance we were paid for" minus "variance that actually happened"
VISUAL   Hedging.pdf "break-even movements" picture: the option's parabola
         over the hedge line. Theta is the vertical drop, gamma is the curvature.
PROOF TO SHOW
  1. Taylor/Ito for the option over dt:
     dC = Theta dt + Delta dS + 1/2 Gamma dS^2
  2. Hedge portfolio: Delta dS + r (C - Delta S) dt
  3. Difference: d eps = -Theta dt - 1/2 Gamma dS^2 + r (C - Delta S) dt
  4. BS PDE: Theta + r S Delta + 1/2 sigma^2 S^2 Gamma - r C = 0
     => -Theta + r(C - Delta S) = 1/2 sigma^2 S^2 Gamma
  5. => d eps = 1/2 Gamma S^2 [ sigma^2 dt - (dS/S)^2 ]   QED
  Consequences:
   - E[Z^2] = 1, so E[d eps] = 0, so the mean error is about 0 (if sigma is right)
   - Var per step = 1/2 Gamma^2 S^4 sigma^4 dt^2 (since Var(Z^2) = 2).
     Summing N steps: N * O(dt^2) = O(T^2/N), so std ~ 1/sqrt(N)
   - mu does not appear anywhere, so the drift does not matter
UNDERLYING
  - Continuous limit (dt -> 0): (dS)^2 -> sigma^2 S^2 dt exactly
    (quadratic variation, Ito isometry in the lecture), so d eps -> 0:
    perfect replication, which is the BS argument itself.
  - Our numbers match the known closed-form approximation for discrete hedging
    (Derman & Kamal 1999, "When you cannot hedge continuously"):
       std(eps) ~ sqrt(pi/4) * sigma * Vega / sqrt(N)
       = 0.886 * 0.2 * 38.17 / sqrt(N) = 6.77/sqrt(N)
       N = 4: 3.38 (sim 3.22) | 12: 1.95 (1.94) | 52: 0.94 (0.95) |
       252: 0.43 (0.44) | 1000: 0.21 (0.22)
    Strong optional slide or Q&A backup. It ties Part 2 to Part 3 (vega).
SAY      "Delta hedging removes the direction of the stock. What is left is a
          bet on how much the stock moves: gamma times (implied variance minus
          realised variance)."

SLIDE 15 - Wrong volatility: from noise to systematic loss
---------------------------------------------------------------------
ON THE SLIDE
  Hedging with sigma = 20%, true vol different:
  True vol    10%     15%     20%    25%     30%
  Mean err    +3.90   +1.97   0.01   -1.98   -3.97
  Std err     1.05    0.73    0.44   1.00    1.92
  About +/-2 per 5 vol points, about 20% of the premium.
VISUAL   notebook: overlaid histograms "Hedging with sigma = 0.20 when the true
         vol is different"
PROOF TO SHOW
  Take the expectation of the slide 13 formula with sigma_real != sigma:
    E[eps] = 1/2 * integral_0^T E[ Gamma S^2 ] (sigma^2 - sigma_real^2) dt
  First-order check: E[eps] ~ C(sigma) - C(sigma_real) ~ Vega * (sigma - sigma_real)
    = 38.17 * 0.05 = 1.91  vs. simulated 1.97 / -1.98. Matches.
UNDERLYING
  - "Gamma = -Theta" (Hedging.pdf eq. 9) only holds if the realised variance
    equals the variance priced in. Otherwise theta (the premium decay we
    collect) and gamma (what the moves cost us) no longer cancel.
  - Std also grows because of the mismatch: path-dependent gamma exposure
    (paths that sit near K for a long time realise the vol mismatch more).
SAY      "A delta hedger who sold the option is short volatility. If the stock
          moves more than priced, the hedge loses money every day. This is the
          biggest risk, as the lecture says: 'the variance delivered is not
          right - BIG problem'."

SLIDE 19 - How each method computes Greeks (and why MC gamma is noisy)
---------------------------------------------------------------------
ON THE SLIDE
  Tree: Delta and Gamma come for free from the first nodes
     Delta = (C_u - C_d)/(S u - S d)
     Gamma = [ (C_uu - C_ud)/(S u^2 - S) - (C_ud - C_dd)/(S - S d^2) ] / (0.5 (S u^2 - S d^2))
     Vega needs 2 extra trees (bump sigma). Error ~ 1/N.
  MC: bump and reprice with COMMON RANDOM NUMBERS, h = 1 (1% of S0)
     Delta ~ [C(S+h) - C(S-h)]/(2h)
     Gamma ~ [C(S+h) - 2C(S) + C(S-h)]/h^2
  Bias-variance trade-off in h. Gamma has about 6x the relative error of delta.
VISUAL   notebook: "MC gamma vs bump size h" (noisy for small h, biased for
         large h) + "Tree: relative error of Greeks (log-log)" +
         "MC: relative SE of Greeks (log-log)"
PROOF TO SHOW
  Bias: Taylor (same as slide 8) gives bias = O(h^2)
  Variance of MC gamma: the payoff is piecewise linear, so its second
  difference is non-zero only for paths with S_T within about +/- h of K.
  That fraction of paths is ~ h. Each such path contributes ~ h/h^2 = 1/h.
  => Var ~ h * (1/h)^2 / M = 1/(h M)
  => MSE = c1 h^4 + c2/(h M), so there is an optimal h. Neither tiny nor
     large h works.
  Common random numbers: Var(X - Y) = Var X + Var Y - 2 Cov(X,Y). Using the same
  Z makes Cov large, so the noise of the difference nearly cancels.
UNDERLYING
  - Tree Greeks are measured at t = dt and 2 dt instead of t = 0. The offset
    is O(dt) and vanishes as N grows.
  - Better MC estimators (mention only): pathwise delta = e^{-rT} 1{S_T>K} S_T/S0
    (no bump, unbiased); likelihood-ratio method for gamma.
SAY      "The tree gets Greeks almost for free. MC has to difference noisy
          numbers, and gamma, a second difference, suffers most."

A1 - Black-Scholes formula from the risk-neutral expectation
  C = e^{-rT} E^Q[S_T 1{S_T>K}] - K e^{-rT} Q(S_T > K)
  Second term: S_T > K  <=>  Z > -d2  =>  Q = N(d2)
  First term: write S_T = S0 e^{rT} e^{-sigma^2 T/2 + sigma sqrt T Z} and complete
  the square in the Gaussian integral (equivalently, change to the stock
  numeraire, Girsanov shift Z -> Z + sigma sqrt T):
     e^{-rT} E^Q[S_T 1{S_T>K}] = S0 N(d1)
  => C = S0 N(d1) - K e^{-rT} N(d2)

A2 - Delta = N(d1) (the "magic cancellation" from Hedging.pdf)
  Identity: S phi(d1) = K e^{-rT} phi(d2)
  Proof: phi(d2)/phi(d1) = exp((d1^2 - d2^2)/2) = exp((d1 - d2)(d1 + d2)/2)
         = exp( sigma sqrt T * [ln(S/K) + rT]/(sigma sqrt T) ) = S e^{rT}/K
  dC/dS = N(d1) + S phi(d1) d'(d1) - K e^{-rT} phi(d2) d'(d2),
  and d'(d1) = d'(d2) = 1/(S sigma sqrt T), so the last two terms cancel => N(d1).
  Gamma = phi(d1)/(S sigma sqrt T),  Vega = S phi(d1) sqrt T follow the same way.

A3 - CRR tree converges to BS
  ln(S_T/S0) = sum of N i.i.d. steps +/- sigma sqrt(dt), with risk-neutral p.
  Mean per step: (r - sigma^2/2) dt + O(dt^{3/2}); variance: sigma^2 dt + O(dt^2).
  CLT => ln(S_T/S0) -> N((r - sigma^2/2) T, sigma^2 T), the BS distribution.
  Payoff is continuous and bounded by S, so the expectations converge.

A4 - Discrete-hedging error variance (detail for slide 13)
  eps_N = sum_i 1/2 Gamma_i S_i^2 sigma^2 dt (1 - Z_i^2)
  Var(1 - Z^2) = 2, so Var(eps_N) ~ 1/2 sigma^4 dt * integral_0^T E[Gamma^2 S^4] dt
  ~ (pi/4) sigma^2 Vega^2 / N   (Derman-Kamal)
  Table: simulated std vs. 6.77/sqrt(N) for N = 4, 12, 52, 252, 1000
  (see slide 13 numbers).
