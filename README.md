Consider a call option on a non-dividend paying stock.
Stock price = $100
Strike = $100
Expiry = 1Y
stock follows a geometric brownian motion.
Vol = 20%

Calculate the option price with:
1. Black-Scholes
2. Monte-Carlo
3. Tree or finite-differences grid

Show results, convergance, and discuss the uncertainty in the numerical results.

With Monte-Carlo sim build a replication portfolio. Along each path, record the difference at expiry between the payoff of the call and the replicating. What do these differences depend on? When des the replication work well, when does it not?

Estimate Delta, Gamme, Vega of the option using 
1. Black-Scholes
2. Monte-Carlo 
3. Tree or finite-differences grid

Comment on you results.
